# Onboarding to a new area

1. Read `.tokencrusher/index.md` — understand the full module structure
2. Pick the module you are working in
3. Read `.tokencrusher/snapshots/<file>.md` for each file in that module
4. Read the actual source files only for the 1–2 files most central
   to your task (identified from the snapshot summaries)

Avoid reading the whole codebase. The snapshots give you 80% of the
context in 5% of the tokens.
