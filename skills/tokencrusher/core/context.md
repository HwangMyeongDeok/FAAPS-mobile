# Reading .tokencrusher/ snapshots

The `.tokencrusher/` directory is auto-generated by the graph engine.
Never edit these files manually — they are rebuilt on every commit.

## index.md

The master module map. Always read this first. Lists every module and
the functions/classes it exports. ~200 tokens total.

Format:
```
## src/auth/
- middleware.ts → [validateToken, requireRole, rateLimiter]
- session.ts → [createSession, destroySession, refreshSession]
```

## impact/\<module\>.md

Impact analysis for a specific module. Shows three sections:

- **Directly affected** — files that import or call symbols from this module
- **Tests to run** — test files that cover the changed symbols
- **Safe to ignore** — everything else (no dependency path to this module)

Read the impact file after identifying the module you are working in.

## snapshots/\<file\>.md

Compact structural summary of a single file — imports, exports, function
signatures with line numbers, class hierarchy. Read instead of the full
source file when you only need structural context (~60–100 tokens).

## What to do if a snapshot is missing

Run `npx tokencrusher build` to regenerate. This takes ~10 seconds for
a 500-file project and under 2 seconds for incremental updates.
